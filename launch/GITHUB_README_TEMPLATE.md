## 3. SEO Backlink Strategy Notes
- **Why Shields.io Badges**: GitHub repositories rank highly on Google. Prominent badges with clear anchor text and direct HTTPS domain links pass contextual relevance for search queries like `"PBR texture generator in-browser"`, `"WebGL 60 FPS studio"`, and `"Three.js procedural runtime"`.
- **Anchor Text Diversity**: Notice the natural distribution of anchors (`lunarparadox.com`, `Launch Studio`, `Explore Tools`, `Open Labs`, `Privacy Policy`). This matches Google's quality rater guidelines for natural editorial links.
