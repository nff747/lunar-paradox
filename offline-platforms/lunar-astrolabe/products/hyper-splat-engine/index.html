HyperSplat: Virtualized WebGPU 3D Gaussian Splatting Engine

Zero-copy 3D Gaussian Splatting and spatial AI engine with distance LoD tile streaming and proactive VRAM paging.

High-throughput spatial rendering engine written in pure WebGPU and WGSL. Features zero-copy SharedArrayBuffer data streaming, octree-based distance Level of Detail (LoD) tiles, sub-pixel splat sorting, and proactive virtual VRAM paging designed to stream 10M+ splat point-clouds smoothly in modern browser viewports.

// WebGPU WGSL Bitonic Radix Splat Sort Kernel
@compute @workgroup_size(256)
fn sortSplats(@builtin(global_invocation_id) id: vec3) {
  let idx = id.x;
  if (idx >= uniforms.splatCount) { return; }
  let depth = calculateViewDepth(splatPositions[idx], uniforms.viewMatrix);
  sortKeys[idx] = packDepthKey(depth, idx);
  workgroupBarrier();
  bitonicLocalSort(idx);
}
