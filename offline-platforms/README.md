# Lunar Paradox — three independent offline platforms

Run Start-syzygy.sh, Start-gravity.sh, or Start-astrolabe.sh.
Alternatively: python3 start.py syzygy (or gravity / astrolabe).
The launcher opens only the selected experience. There is no combined homepage.
Keep the terminal open while viewing; Ctrl+C stops the local server.

All runtime assets are included. A WebGL2 browser is required.
Python is needed for the backend only; each platform index.html is also a
self-contained live WebGL export. Direct file execution remains an unverified
browser compatibility gate. Use the launchers for the tested local runtime.
Syzygy serves Brand/Home and Studio; Gravity serves Labs; Astrolabe serves Products.
SCENE retains scene controls and saved views. SCENE > Local publisher manages content.
Applications are reviewed before pricing is unlocked. SCENE > Applications & pricing opens the owner desk.
See each platform COMMISSIONING.md. Email delivery, public hosting and payment are not configured.
Read each platform COMPANY-INFRASTRUCTURE.md before publishing or distributing content.
External message delivery, public backend authentication and hosted deployment are not configured.
DATA (Syzygy) and ARCHIVE (Gravity/Astrolabe) contain saved views; View / Sound
opens graphics and volume settings. Astrolabe also has a header settings button.
Saved records can be named, restored, removed and recovered with Undo.
Telemetry reports measured local scene values and renderer activity; there is no
fabricated external mission data feed. See previews/CURRENT-VALIDATION.md for the
current evidence and remaining performance and visual acceptance gates.
On narrow Astrolabe screens, open the chapter menu for ARCHIVE / GRAPHICS.
Sound starts muted. Enable it with the speaker control in the experience.
Saved views include the camera and timeline; they do not serialize individual
particle velocities or restore an actively held fracture.
The supplied reference screenshots are not used as scene backdrops.
