# Lunar Paradox — Gravity

This is a separate interactive WebGL experience. All engine modules, fonts,
textures and synthesized audio are local. Internet is not required.

For the full local backend, from the parent offline-platforms folder run:

    python3 start.py gravity

Or run the matching Start-gravity.sh launcher. Keep its terminal open.
If the browser does not open, copy the printed localhost URL into your browser.
Python 3 and a WebGL2 capable browser are required; no package install is needed.
The live Three.js engine, shaders, textures and fonts are embedded in index.html,
so the scene has no runtime module or CDN dependency. Direct file opening is
provided but has not been verified through the browser review tool; use the
launcher for the tested HTTP/SQLite path.
Direct file mode uses browser storage when available. The launcher adds a real
SQLite backend for settings and saved scene snapshots on 127.0.0.1.
